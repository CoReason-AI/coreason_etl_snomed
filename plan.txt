# Problem Analysis
The task is to implement the "Silver (The Refinery)" and "Gold (The Product)" layers of the Medallion Architecture for the SNOMED CT data pipeline.
The FRD defines the following atomic units for implementation:

1. **Silver Layer: Concept Transformation**
   - Read raw `sct2_Concept_Snapshot_*.txt` using `polars`.
   - Filter `active == 1`.
   - Cast `id` to `pl.Utf8`.
   - Parse `effectiveTime` to `pl.Date` (format: `%Y%m%d`).
   - Add `coreason_id` using `UUID5(NAMESPACE_SNOMED, id)`.

2. **Silver Layer: Description Transformation**
   - Read raw `sct2_Description_Snapshot_*.txt` using `polars`.
   - Filter `active == 1`.
   - Cast `id` and `conceptId` to `pl.Utf8`.
   - Parse `effectiveTime` to `pl.Date` (format: `%Y%m%d`).
   - Add `coreason_id` using `UUID5(NAMESPACE_SNOMED, id)`.
   - Add `concept_coreason_id` using `UUID5(NAMESPACE_SNOMED, conceptId)`.

3. **Silver Layer: Relationship Transformation**
   - Read raw `sct2_Relationship_Snapshot_*.txt` using `polars`.
   - Filter `active == 1`.
   - Cast `id`, `sourceId`, `destinationId`, `typeId` to `pl.Utf8`.
   - Parse `effectiveTime` to `pl.Date` (format: `%Y%m%d`).
   - Add `coreason_id` using `UUID5(NAMESPACE_SNOMED, id)`.
   - Add `source_coreason_id` using `UUID5(NAMESPACE_SNOMED, sourceId)`.
   - Add `destination_coreason_id` using `UUID5(NAMESPACE_SNOMED, destinationId)`.
   - Add `relationship_type_coreason_id` using `UUID5(NAMESPACE_SNOMED, typeId)`.

4. **Gold Layer: `dim_snomed_concept` Generation**
   - Join Silver Concept with Silver Description on `conceptId`.
   - Filter Description for `typeId == '900000000000003001'` (Fully Specified Name).
   - Produce the final schema and save/yield.

5. **Gold Layer: `bridge_snomed_synonym` Generation**
   - Process Silver Description.
   - Filter for `typeId == '900000000000013009'` (Synonym).
   - Produce a mapping from `coreason_id` to an array of synonyms.

6. **Gold Layer: `fact_snomed_relationship` Generation**
   - Process Silver Relationship.
   - Produce the final schema using chunking/sink_parquet to avoid OOM.

The user explicitly requires selecting **ONE Atomic Unit** and implementing it.
The "One Step" Rule says: Choose one and only one atomic unit from your list to implement in this iteration. Select the smallest possible increment that moves the project toward the goal.
